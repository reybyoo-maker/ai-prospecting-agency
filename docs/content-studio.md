# Content Studio

## Tujuan
Menghasilkan aset konten untuk unggah manual. Flow ini terpisah dari panel Database Scraping.

## Alur
Gemini strategy → rencana 7 hari → skrip 7 slide → render visual → PNG/JPG/PDF → aset GitHub dan content_manifest.json.

## Standar
Setiap hari memiliki hook, satu insight utama, kerangka praktis, contoh bisnis realistis, kesalahan/keberatan, dan CTA. Tema visual menggunakan biru muda, biru tua, dan putih. Generator memeriksa kelengkapan rencana, peran slide, panjang copy, hook, CTA, dan arahan visual.

## Penyimpanan
File PNG/JPG/PDF serta manifest disimpan di GitHub. Tidak ada sinkronisasi spreadsheet atau database eksternal.

## Publikasi
Aset diunggah manual ke Instagram/TikTok. Tidak ada auto-publish, auto-DM, atau auto-comment.
